# 学習ドキュメント一覧

`docs/` 配下の学習用ドキュメント一覧です。まず全体像を掴み、その後に会話制御、LLM、フロント、音声、ツール、外部連携、永続化の順で読むと実装との対応を追いやすくなります。

- 1. [全体アーキテクチャとイベントグラフ](./全体アーキテクチャとイベントグラフ.md)
  - `graph.Stage` を軸に、`wschat`、`rtc`、`conversation`、`responsesapi`、`toolcaller`、`sessionlifecycle`、`diary store` がどう接続されるかを俯瞰する導入資料です。
- 2. [会話オーケストレーション](./会話オーケストレーション.md)
  - `conversation` を会話進行の正本として捉え、発話確定、割り込み、streaming chunk、tool 実行後の継続、TTS 完了、session clear までの制御を整理しています。
- 3. [LLM連携と出力契約](./LLM連携と出力契約.md)
  - `responsesapi` と `system_prompt.txt` を中心に、NDJSON による `speech` / `wait` 契約、tool call、tool result 後の follow-up の扱いを説明しています。
- 4. [Webフロントと接続ライフサイクル](./Webフロントと接続ライフサイクル.md)
  - `web/src/main.tsx` ベースの React UI について、管理画面とアプリ画面、WebSocket 接続、WebRTC signaling、状態表示の設計をまとめています。
- 5. [音声パイプライン](./音声パイプライン.md)
  - ブラウザのマイク入力、サーバー側 VAD / Google Speech-to-Text、ElevenLabs TTS、WebRTC 音声返却までの音声経路を追う資料です。
- 6. [ツール実行基盤](./ツール実行基盤.md)
  - `registry`、`toolcaller`、handler 共通インターフェース、tool result の再投入と UI 表示の二重用途を整理しています。
- 7. [Googleカレンダー連携](./Googleカレンダー連携.md)
  - OAuth、token 永続化、`CalendarClient`、会話文脈への予定注入、予定の参照・作成・更新ツールのつながりを説明しています。
- 8. [生活操作ツール群](./生活操作ツール群.md)
  - SwitchBot シーン実行、Hub 2 環境取得、`schedule_timer`、`set_whiteboard` など、生活操作や UI 更新系ツールの役割をまとめています。
- 9. [タイマー・日記・自動リセット](./タイマー・日記・自動リセット.md)
  - timer、`write_diary`、`sessionlifecycle` を通じて、時間経過と継続記憶をどう扱うかを整理した資料です。

補助資料:

  - Web UI、音声入出力、Google Calendar OAuth、タイマー通知までを手で確認するための最小手順書です。
